## How WinCatalog Sits

WinCatalog does not replace Explorer, the drive letter, or the discs you already own. It sits beside them as a named catalog for one job: which volumes are listed, which files are indexed, and what the next person should search. A local WinCatalog profile is enough for everyday work.

If two people share a PC, each keeps a WinCatalog style of their own. The catalog stays small on purpose. Extra discs wait for their own title instead of crowding the live set.

A first visit should be one short scan, then the same WinCatalog catalog the next day. That is enough to see if the layout holds.

## Traffic Light

| Signal | On the WinCatalog board | What you do |
|--------|----------------------|-------------|
| Green | Named catalog, short volume list | Continue the same scan |
| Amber | Two shelves mixed in one catalog | Split the set before a large scan |
| Red | No title, no note, discs unlabeled | Stop and name the catalog first |
| Clear | Handoff written, volumes few | Close WinCatalog and leave the catalog |

## Open Order

1. Open the last WinCatalog catalog, not a new empty list.
2. Read the volume list and the last handoff.
3. Finish one visible scan inside WinCatalog.
4. Write what changed, then close with fewer loose discs than you found.
5. If the set feels crowded, drop anything that belongs to a different WinCatalog job.

## After a Week

A week in WinCatalog is not a bigger catalog. It is the same title, a shorter volume list, and a note that still makes sense on Monday. If every disc is live, nothing stands out. Take finished volumes off the live set so the next visit starts on the disks that are still in play.

Other programs stay where they are. WinCatalog only keeps the path back: catalog name, volume list, summary, handoff.

Leave WinCatalog with a quieter catalog than the one you opened. The next visit should start on that catalog, not in a search through unlabeled discs.

## Sign-off

- [ ] The WinCatalog workspace name is short enough to scan
- [ ] Only live volumes are listed
- [ ] A second person can read the handoff
- [ ] The last WinCatalog catalog still opens after a restart
- [ ] Finished discs are off the live WinCatalog set
- [ ] The WinCatalog summary still matches the volumes on the list

## Field Note

WinCatalog is easier to trust when the catalog stays smaller than the pile of discs it came from. Name the session, keep the live volumes, finish one visible scan, and write what changed. Extra jobs wait for their own title.

The same loop fits a media shelf, a client archive, or a shared computer. Open the last WinCatalog catalog and continue. Do not rebuild the layout from scratch.
